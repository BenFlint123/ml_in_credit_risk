# ml_in_credit_risk
This is a repo created to experiment with various machine learning techniques in credit risk contexts.


ML techniques currently explored:
- gradient boosting
- lasso / ridge logistic regression
- PCA
- Factor Analysis
- comparison with conventionaly logistic regression model

The data used to develop this code is Lending club's public_dataset_loans dataset:
https://www.kaggle.com/datasets/adarshsng/lending-club-loan-data-csv?select=loan.csv
